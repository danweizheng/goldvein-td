# 音频素材来源台账

> **用途**：记录每一个音频文件的来源、作者与许可，作为被投诉时唯一的自证材料。
> **纪律（决策 D7：全部 CC0）**：只收录 **CC0 / Public Domain**。CC-BY 有署名义务、CC-BY-NC 禁止商用，一律排除。
> **维护时机**：每次新增音频文件时同步登记，未登记的文件不得进入 `public/assets/audio/`。

---

## 收录标准

| 许可 | 是否可用 | 说明 |
|---|---|---|
| CC0 1.0 / Public Domain | ✅ 可用 | 无需署名，可商用，可修改 |
| CC-BY 4.0 | ❌ 排除 | 需署名，会给发布带来额外义务 |
| CC-BY-NC | ❌ 排除 | 禁止商用；即使免费发布也有风险 |
| MIT / Apache（音频） | ✅ 可用 | 极少见，需确认覆盖音频资产本体 |
| 来源不明 / 未标注 | ❌ 排除 | **绝不复刻原作「来源不明的胜利音乐」的做法** |
| OGA-BY 3.0（即使与 CC0 双许可） | ⚠️ 本次未采用 | 双许可之一为 CC0 时法律上可用，但为台账零歧义，本次全部改用单一 CC0 素材 |

**推荐素材库**：Freesound（CC0 筛选）· OpenGameArt（CC0）· Kenney.nl（全套 CC0）· Pixabay Audio

**本次实际使用的库**：Kenney.nl（全 5 个音效包）· OpenGameArt（CC0 过滤，`field_art_licenses_tid[]=4`）。
Freesound 与 Pixabay Audio **未使用**：Freesound 下载需登录账号，Pixabay Audio 页面为 JS 渲染且其许可是「Pixabay Content License」而非 CC0 1.0，与本项目 D7「只取 CC0」的纪律不符。

**「已核查」列的含义**：`☑` = ① 已打开来源页面（或解压包内 `License.txt`）确认作者署名与许可标注为 **CC0 1.0**；② 已核对落盘文件时长与体积满足 [§格式与体积](#格式与体积核对) 的约束。`☐` = 未核查（本表内不允许出现）。

## BGM 撞车自查

> 策划案 §7.3 纪律 3 要求：正式发布前用音频指纹工具（如 AcoustID）核查 4 首 BGM 是否已在知名游戏中被使用。

### 核查方法（本次实际执行）

**方法 A —— AcoustID 指纹反查：无法完成（技术阻塞，非跳过）**

- AcoustID 官方 API `https://api.acoustid.org/v2/lookup` 强制要求 `client` 参数（需用邮箱在 https://acoustid.org/new-application 注册应用后取得 API key）。
- 本机已实测匿名调用：`https://api.acoustid.org/v2/lookup?duration=154&fingerprint=<指纹>` 返回 **HTTP 400 Bad Request**（空 body）。**没有可用 API key，因此 AcoustID 反查本次无法执行。**
- 已为 4 首 BGM 生成 **chromaprint 指纹**（ffmpeg 内置 chromaprint muxer，无需额外安装），拿到 key 后即可一条命令完成核查：

```bash
# 生成指纹（已执行，结果见下表「指纹 SHA1」列）
ffmpeg -i public/assets/audio/bgm_menu.ogg -f chromaprint -fp_format base64 -

# 拿到 client key 后反查
curl "https://api.acoustid.org/v2/lookup?client=<API_KEY>&meta=recordings+releasegroups&duration=<秒>&fingerprint=<指纹>"
```

**方法 B —— 等价手段（本次实际采用的判定依据）**

1. **素材页流量指标**：OGA 素材页的 `[N download(s)]` 与 `Favorites` 数量。下载数千次 / 收藏上百次 = 被大量小游戏复用的高概率信号。
2. **素材页评论区逐条阅读**：检索作者页公开自述中的复用声明（`used it` / `in my game` / `Steam` / `itch.io` / `Google Play` / `our main theme` 等关键词）。
3. **站外检索**：DuckDuckGo 检索「曲名 + 作者名」，确认是否存在第三方游戏引用。
4. **同名排除**：区分「曲名与某知名游戏重名」与「该曲被某知名游戏使用」，前者不构成撞车。

**方法 B 的固有局限（必须在发布前补齐）**：等价手段只能覆盖**在素材页公开自述过复用**、或**被搜索引擎收录**的复用；对未留言、未被索引的复用**完全无覆盖**，也不具备 AcoustID 的跨库指纹匹配能力。**因此下表「通过」是基于公开证据的保守判定，不等价于指纹级确认。**

### 生成与处理说明（可复现）

- **BGM**：源文件 → 解码为 PCM 中间文件 → `libvorbis -q:a 2 -ar 44100`，立体声。
  ⚠️ 必须走 PCM 中间：从 `.ogg` 源直接二次压缩会产生**非单调时间戳**（ffmpeg 报 `non monotonically increasing dts to muxer`）。经 PCM 中转后 4 首 BGM 告警数为 0。
- **Kenney 音效**：源文件本身即 `.ogg` 且 < 200 KB，**原文件直接落盘、未重编码**（无损保留原始音质）。
- **OGA 音效**：`.ogg` 源直接落盘；`.wav` 源统一转 `libvorbis -q:a 2` 单声道。
- **`sfx_win.ogg` / `sfx_lose.ogg`**：原曲长 56.74s / 45.10s，分别截取**前 20s / 前 15s**（jingle 不需要完整曲长）。
- **`sfx_amb_vault.ogg`**：原曲 123.00s，截取 **6s–36s**（30s）。
  **`sfx_amb_street.ogg`**：原曲 119.31s，截取 **10s–40s**（30s），44 kbps 单声道（原曲长度无论如何都塞不进 200 KB）。
  ⚠️ **这两段是无缝循环素材的片段，接缝处未做 crossfade**，引擎侧需自行做 0.1–0.3s 淡入淡出或交叉淡化，否则循环点会听到「咔哒」。
