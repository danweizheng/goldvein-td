```powershell
cd E:\tower-defense
pnpm dev
```

然后打开控制台打印的地址（默认）：

```
http://127.0.0.1:5173/
```

## 2. 试玩者该看什么（**这是本说明的重点**）

按优先级排列。每条我都给了"怎么做"和"看到什么意味着什么"。

### ① 窃金飘字与钱包条下降是否"**同拍**" ← 最重要

**这是本次要判的核心：偷钱爽不爽。**

**怎么做**：开局在 ★停顿点（地面金色高亮格）旁边点两座**神偷系**塔，等第 1 波敌人走进射程。

**看什么**：
- 命中瞬间，敌人头上弹出金色 `+N`；
- **同一瞬间**，敌人头顶那根**金色钱包条**应当变短一截。

**为什么特别要问这个**：钱包条（暗槽变长 = 被偷走的部分）是本作**唯一**能一眼看到"我在偷钱"的东西
（比血条重要）。但**我自己无法确认这两者是否视觉同拍** —— 我的模型**读不了图**，
只能证明"窃金事件确实产生了"（实测 `stealEvents=90`）。
**如果飘字在跳、钱包条却看不出在掉，请立刻告诉我**：那就是这个机制没做出来。

### ② 卡位反馈能不能被感知（决定军训系去留）

**背景**：军训系（阻挡）现在值不值得存在，是项目的待决问题（Q1）。
已裁决：**不做"移速条"，用替代反馈**（锁图标 + 刻度变红 + 钱包条加亮）。

**怎么做**：
1. 按 `4` 选中**军训系**（面板第 4 项）→ 此时地图上会出现**红色虚线圆**（阻挡范围，覆盖路径）；
2. 把它建在 ★停顿点紧邻处，旁边再放一座神偷；
3. 看被它拦住的敌人脚下：应当出现一个**小挂锁**，且那一小格刻度**变红**；
4. 同时看该敌人头顶的**钱包条**：被阻挡时它应当是**亮黄**（其余时刻是普通金色）；
5. 看 HUD 第二行的 **"卡位额外 +N"** —— 这是量化结果（契约 §14.8 的**增量**语义）。

**你要回答的**：**"我说不出军训系有没有在起作用"** 还是 **"我能看出它把敌人锁住了、并且多偷到了钱"**。
若是前者，我们再谈加"移速条"。

（自动化侧的对照已成立：同一画面、同一鼠标位置，选神偷 = 0 个红像素；选军训 = 166 个红像素。）

### ③ 占位美术能不能"一眼分辨"

编码规则（`docs/art/占位美术方案.md`）：**塔系 → 轮廓形状**、**品阶 → 底部齿数**、
**护甲 → 边框色**、**飞行 / BOSS / 精英 / 窃金抗性 → 附加标记**。

**怎么做**：一边打一边看敌人：

- 你能不能在**不看 HUD**的情况下，说出这一波来的是**轻甲**还是**城甲**？
  （这决定你该造穿刺还是攻城 —— 波次预告面板也会直接告诉你推荐攻击类型）
- 敌人的**挂锁**标记能不能让你意识到"这个偷不动"？

**若看不出**：请指出是哪一条编码失效（护甲 / 齿数 / 挂锁），这是可修的。

### ④ 正经玩能不能打到**第 14 波**

**我的实测基线（务必对比）**：自动脚本能做的只有"点 6 座塔、不升级、不研究"，
**第 4 波就漏了 13 只**（N1 共 50 命）。

**你要做的**：正常玩 —— 升级（选中塔按 `U`）、堆射程、在 ★停顿点叠塔、按 `Q/W/E` 研究科技。

**若你也在第 10 波前后就开始漏**：说明**前中期的"金币 → 战力"转换不够顺**，那是设计问题不是操作问题，
请告诉我漏的是哪一型敌人。

### ⑤ 第 10 波是不是"**太轻松**"

**背景**：平衡侧用 AI 跑了 9 轮，算出第 10 波的需求/上界只有 **0.01×**（即"理论上完全无压力"）。
**这件事人一分钟就能确认**：如果第 10 波你几乎不用操作就过了，那 AI 的读数就是对的；
如果你手忙脚乱，说明模型与真人体验有落差 —— **两种结论我都需要**。

## 4. 操作一览（首次试玩必看）

| 操作 | 键 / 鼠标 |
|---|---|
| 建塔 | 点空地（先按 `1`–`6` 选塔系；面板就在左下角，显示造价与"买不起"） |
| 选中塔 / 看详情 | 点塔（右侧显示**窃金/秒**与已窃取总额 —— 判断"值不值"的关键指标） |
| 升级 / 出售 | `U` / `S` |
| 撤销上一次建造 | `Ctrl+Z`（10 秒内） |
| 暂停 / 倍速 | `空格` / `F`（1x → 2x → 4x） |
| 缩放 | 鼠标滚轮 |
| 技能 | `R` 领工资 ｜ `T` 荆棘丛林 ｜ `G` 点金术（无 UI 按钮，仅快捷键） |
| 研究科技 | `Q` `W` `E`（前三条科技线，各按一次升一级） |

**最重要的一格**：左下角建造面板的第 1 项就是**神偷系**（核心经济塔）。
放在 ★停顿点（金色高亮格）旁边，敌人经过时会停 0.6 秒 —— 那是窃金最优位。

## 5. 明确**没有做**的东西（别浪费时间找）

- **没有主菜单 / 存档 / 局外成长**（圣物、结晶、蜕变结算都没接）。
- **技能只有快捷键**，没有按钮与冷却环。
- **建造项定位**只有 3 档粗标签（核心·偷钱 / 卡位 / 输出）。
- **窃金/秒 是整数截断**（没有小数）。
- **点金术秒杀的那批敌人没有专属飘字**。
- **移动端未适配**（M6）。
- 30 波在数据里存在，但**我从未验证过一整局 30 波的人肉可玩性** —— 第 14 波是发起人这次的门禁线。
